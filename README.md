# Словник — мастерская словарных игр

Рабочая первая версия по ТЗ: восемь механик, пять визуальных тем, редактор сцены, словарь, проверка заданий, сохранение с ресурсами и автономный экспорт. Статическое приложение без зависимостей и обязательного бэкенда.

## Запуск и проверки

`python3 -m http.server 4173 --directory dist`

Откройте http://localhost:4173. Проверки: Node.js 22+, `npm test`. Установка пакетов и сборка не требуются.

## Работа

1. Добавьте слова в «Словарь». Импорт: TXT, CSV, JSON, XLSX. Текст разделяется переносами строк, запятой и точкой с запятой. XLSX: первый столбец первого листа; требуется браузер с DecompressionStream deflate-raw, иначе используйте CSV. JSON: массив строк/объектов с word, wrong, hint, explanation либо объект с массивом words.
2. Выберите возраст, игру и атмосферу. Ручные правки и словарь сохраняются.
3. В «Задания» проверьте автоматически созданные ошибочные варианты. Без подтверждения экспорт блокируется.
4. Добавьте объекты, перетащите на сцене. Размер, поворот, слой, прозрачность и блокировка — в панели объекта.
5. «Предпросмотр» показывает старт игры, «Тест» запускает задания.
6. Скачайте переносимый .slovnik и автономный HTML.

Автосохранение — IndexedDB с вложенными data URL, при возвращении предлагается восстановление. История до 50 изменений в текущей сессии. Для резервной копии используйте .slovnik.

«Словарный сейф»: запомните слово и нажмите «Запомнил — открыть замки». Слово скрывается частично: восстановите буквы, открывая замки. Возраст определяет число пропусков (1–4). Баллы начисляются за целиком открытый сейф, ошибка расходует жизнь. Обязательного таймера запоминания нет. Изображения и разметка для этой игры не нужны. Старые проекты с предыдущим восьмым шаблоном автоматически открываются как «Словарный сейф», при этом словарь, правки и прежние ресурсы сохраняются.

## Экспорт и Genially

Автономный HTML включает движок, CSS и все загруженные ресурсы. Работает без сети. Панели редактора и служебный футер не экспортируются. Компактный вариант удаляет комментарии и отступы. PNG/JPEG оптимизируются до WebP с сохранением прозрачности. GIF и WebP сохраняются без перекодирования, чтобы не потерять анимацию. Оптимизацию можно выключить.

Копирование создаёт iframe с srcdoc. Если площадка блокирует srcdoc, разместите скачанную игру на GitHub Pages и вставьте URL через iframe. Совместимость непосредственно с Genially требует ручной проверки на площадке.

## GitHub Pages

Репозиторий: https://github.com/galmizmaria-beep/slovhik. Для включения сайта откройте Settings → Pages → GitHub Actions. Включён workflow `.github/workflows/pages.yml`: тесты и публикация `dist`. Относительные пути поддерживают подпапку репозитория. После включения Pages запустите workflow Publish Slovnik во вкладке Actions, если он не запустился автоматически.

## Структура

- `dist/core/model.js`: схема, реестр механик, валидация, словарь, IndexedDB.
- `dist/core/runtime.js`: единый движок для тестирования и экспорта.
- `dist/core/xlsx.js`: локальный импорт XLSX.
- `dist/app.js`: редактор, импорт/экспорт, сцена и история.
- `dist/styles.css`, `dist/game.css`: оформление редактора и игры.
- `tests/`: модель, миграция, сейф, переносимость, большой словарь.

## Границы первой версии

Все восемь механик запускаются; лабиринт и космос представлены упрощёнными последовательностями заданий. Пять тем используют SVG-ландшафт и отдельные emoji/пользовательские картинки. Это ещё не полные PNG/WebP-наборы состава, указанного в ТЗ. 32 семейства шрифтов доступны с fallback на Arial, файлы веб-шрифтов в игру не встраиваются.

Следующий этап: независимые стили всех текстовых ролей; PNG/WebP-библиотеки; множественные/устные ответы, сопоставление и сортировка; маппинг CSV-колонок; Web Workers с отменой; оформление медиа финальных экранов; серии/бонусы; локализация. Размер объекта задаётся в панели или перетаскиванием маркера выбранного объекта. Масштабирование картинок сохраняет пропорции. Слова проходят все раунды без фиксированного лимита.

В редакторе Manrope/Literata могут загружаться из Google Fonts. Пользовательские данные и медиа никуда не отправляются. Автономный экспорт не обращается к внешним шрифтам.
